# 改后缀小轮盘 · Filee LW

Filee LW 用鼠标圆盘批量恢复压缩包的文件名，支持 Windows 和 macOS。程序在原目录改名，保留文件内容。改名后请用解压工具打开文件。

## Windows 下载与使用

1. 下载 [FileeLW.exe](https://github.com/luqiyan0114/Filee_LW/releases/download/v9/FileeLW.exe)，以普通权限双击运行。程序会在系统托盘显示蓝紫色圆环图标，无需解压或编译。
2. 在资源管理器中先选中一个或多个文件并松开鼠标，再按住 **Ctrl + Shift**，从已选中的文件上按住左键拖动。
3. 圆盘出现后，向左选择 **ZIP**，向右选择 **7z 分卷**。指针拖出圆环后，该侧仍会高亮。松开左键执行高亮的操作，回到中心松开则取消。

## macOS 下载与使用

1. 下载 [macOS 通用版](https://github.com/luqiyan0114/Filee_LW/releases/download/v9/FileeLW-v9-macos-universal.zip)，解压后将 `Filee LW.app` 移到「应用程序」并打开。支持 macOS 12 及以上的 Apple 芯片和 Intel Mac。
2. 在「系统设置 → 隐私与安全性 → 辅助功能」中允许 Filee LW 接收手势。点击菜单栏的圆形箭头图标，选择「启用手势与 Finder 权限」，按提示允许 Filee LW 控制 Finder，以读取当前选中的文件。
3. 在 Finder 中先选中文件，再按住 **Control + Shift** 拖动。左侧是 ZIP，右侧是 7z 分卷。拖出外圈仍然有效，回到中心松开或按 **Esc** 可取消。

macOS 版使用临时签名，未经 Apple 公证。若首次打开被系统拦截，可在「隐私与安全性」中核对应用后选择「仍要打开」。

## 每个操作会发生什么

| 操作 | 结果 |
| --- | --- |
| 向左松开 | 将每个选中文件的最后一段后缀改为 `.zip`，如 `资料.tar.dat` → `资料.tar.zip`。已有 `.zip` 后缀的文件跳过。 |
| 向右松开 | 按文件名的自然顺序为选中文件编号。每个目录分别处理，已有 `.7z.数字` 后缀的文件跳过并提示。 |
| 在中心松开 | 关闭圆盘，文件名和剪贴板保持原样。 |
| 在 Windows 双击托盘图标，或在托盘／菜单栏中选择“使用说明” | 打开手势说明。 |
| 托盘／菜单栏菜单选择“退出” | 结束程序。再次打开应用即可重新启用手势。 |

### 7z 分卷如何命名

- **目录里没有 `.7z.001`**。使用自然排序后第一个待改名文件去掉最后一段后缀的名称。比如 `分卷2.dat`、`分卷10.dat` 会依次成为 `分卷2.7z.001`、`分卷2.7z.002`。
- **目录里有一个系列**。沿用该系列的名称，从现有最大编号继续。比如已有 `资料.7z.001` 和 `资料.7z.003`，下一项是 `资料.7z.004`。
- **目录里有多个系列**。弹窗让你选择要续编的系列，取消会跳过该目录。编号依据文件名排序，请在解压前核对它是否符合原始分卷顺序。

### 密码与处理结果

- 选择 ZIP 或 7z 后，程序会尝试将预设的通用解压密码写入剪贴板，替换原有内容。即使有文件跳过或改名失败，程序也会尝试复制密码。解压软件要求密码时，可直接粘贴。
- 处理顺利时圆盘直接关闭。目标已存在、权限不足、选中目录或密码复制失败时，程序会弹窗说明，已有同名文件会保留。批量处理时，已经成功改名的文件会保留新名称。
- 文件夹内容保持原样。程序只改文件名，压缩格式和分卷内容取决于原文件。
